# Format and print a validation result

Format and print a validation result

## Usage

``` r
# S3 method for class 'bmmtools_validation'
format(x, ...)

# S3 method for class 'bmmtools_validation'
print(x, ...)
```

## Arguments

- x:

  A `bmmtools_validation`.

- ...:

  Not used.

## Value

[`format()`](https://rdrr.io/r/base/format.html) returns the lines;
[`print()`](https://rdrr.io/r/base/print.html) writes them and returns
`x` invisibly.
